Whispers from the Archives

Even the Holocron's own login system answers to a higher authority. There is a system account that appears on no roster and in no profile - Lord Vader had it created quietly, and its name is spoken nowhere. Yet the gate is not silent: pass through it and it sends you onward addressed by the very name it matched. A seeker who can make the login resolve to one account after another, and read where each sends him, will in time hear the name that was never written down - and only then can he ask the gate for that name alone.
